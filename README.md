# 🎨 InsAuto — Instagram AI 内容生成助手

AI 自动生成产品图片 + 英文文案 + 标签，你挑选后手动发布；也可开启「定时自动生成」，到点把新内容放进草稿箱。

> **发布权在你**：程序只负责生产内容，不登录、不操作 Instagram 账号。

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置密钥
把根目录 `.env.example` 的内容复制到 `ins账号自动化/data/.env`，填入：
- `OPENROUTER_API_KEY`（必需）：https://openrouter.ai/keys
- `GEMINI_API_KEY`（可选，强烈推荐，免费 500 张/天）：https://aistudio.google.com/apikey

### 3. 启动
| 方式 | 操作 | 说明 |
|---|---|---|
| 桌面控制面板（推荐） | 双击 `启动面板.bat` | 启停网页/定时服务、立即生成一条、实时日志 |
| 网页面板 | 双击 `启动.bat` | http://localhost:8501 |
| 定时生成服务 | 双击 `启动定时生成.bat` | 或由桌面面板启动；保持窗口开启 |

### 4. 生成 → 复制 → 手动发布
1. 「内容工作室」一键生成图片 + 文案 + 标签，或「批量生产」一次生成多条；
2. 草稿箱里点「📋 取用」：复制完整文案（含标签），点「📂 打开图片文件夹」取走图片；
3. 到 Instagram（手机 App 或网页版）发布；
4. 回到草稿箱点「✅ 已发布」，计入发布记录与统计。

## 功能

| 功能 | 说明 |
|---|---|
| ✏️ 内容工作室 | 一键生成图片+英文文案+标签；上传图片生成文案；标签工具；批量生产 |
| 📤 取用（复制/图片） | 草稿、素材都可一键复制完整文案、打开图片文件夹，方便手动发布 |
| 🎨 多图片引擎 | Gemini（推荐）/ Pollinations（免费）/ OpenRouter，生成后自动裁剪为所选比例 |
| 📋 草稿箱 & 审核中心 | 编辑、提交审核、通过后回到草稿箱待发布 |
| 📂 内容管理 | 关键词/主题/标签/状态筛选 |
| ⏰ 定时自动生成 | 间隔 N 天或每天定点，自动「生成→存入草稿箱」，关机错过自动补发 |
| 📊 Dashboard & 统计 | 生成/发布计数、近 30 天趋势、活动日志 |
| 🖥️ 桌面控制面板 | 管理全部服务，状态一目了然 |

## 定时自动生成说明

1. 在网页面板「设置 → ⏰ 定时生成」或桌面面板里配置：启用、模式（间隔 N 天 / 每天）、时间、品类（可随机）。
2. 启动定时服务（桌面面板按钮，或双击 `启动定时生成.bat`）。服务每 30 秒检查一次，到点自动执行。
3. 每次自动生成 = 随机选产品 → 生成图片 → 生成英文文案+标签 → 存入草稿箱，等你手动发布。
4. 生成失败会写入活动日志（Dashboard 可见）并计入失败数。
5. 同一时刻只会有一个生成任务（锁文件保护，防止重复生成）。

## 文案与提示词

- 文案默认英文：钩子开头 + 短句正文 + 互动收尾（IG 只显示前约 125 字符，钩子决定点击率）。
- 风格：casual / luxury / fitness / minimal / educational / sale；「文案额外指令」可追加硬性要求。
- 「内容主题」会同时注入图片、文案、标签三处提示词。
- 标签中英混合、自动去重；复制/取用时按「标签数量上限」（默认 15，最多 30）截断。
- 文案/标签模型默认 `google/gemini-2.5-flash`，可在设置里换成 `qwen/qwen3-30b-a3b`（更便宜）等。

## 项目结构

```
├── app.py                  # Streamlit 网页面板
├── launcher.py             # Tkinter 桌面控制面板
├── scheduler.py            # 定时生成服务（循环检查 + 拉起 worker）
├── worker.py               # 单次自动生成（独立进程，避免长任务卡住界面）
├── assets/                 # 应用图标（由 tools/make_logo.py 生成）
├── tools/                  # 工具：图标生成 / 页面冒烟测试
├── 启动.bat                # 启动网页面板
├── 启动面板.bat            # 启动桌面控制面板
├── 启动定时生成.bat         # 启动定时生成服务
└── ins账号自动化/           # 核心包
    ├── content.py          # 图片生成 + 文案/标签提示词
    ├── automation.py       # 定时生成管线 + 计划时间计算
    ├── db.py               # SQLite 存储
    ├── logger.py           # 活动日志
    └── config.py           # .env 加载（ins账号自动化/data/.env）
```

## 常见问题

- **图片生成失败**：检查网络与 OpenRouter 余额；配置免费 GEMINI_API_KEY 可大幅提升质量与稳定性。
- **定时没执行**：确认定时服务在运行（桌面面板有状态灯），且「启用定时自动生成」已勾选。
- **怎么发布**：草稿箱 →「📋 取用」复制文案 →「📂 打开图片文件夹」取图 → 到 Instagram 发布 → 回来点「✅ 已发布」。
- **换电脑**：重装依赖、把 `ins账号自动化/data/`（密钥 + 数据库）拷过去即可。
- **跑页面冒烟测试**（可选，开发者自检用）：先 `python -m playwright install chromium`，再运行 `python tools/smoke_ui.py`。
